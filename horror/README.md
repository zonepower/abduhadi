# البيت المهجور — الفصل الأخير

لعبة رعب من منظور الشخص الأول، بطور قصة كامل من خمسة فصول، حوارات **صوتية**
عربية، وخط أنابيب رسوميات بتتبّع أشعة في فضاء الشاشة — كل ذلك في المتصفح
وبدون أي ملف أصول خارجي (كل المواد والأصوات تُولَّد وقت التشغيل).

> ليلةُ مطر، سيارةٌ معطّلة، وبيتٌ لا يخرج منه أحد. كريم وابنته ليلى يدخلان
> بحثاً عن مساعدة. أحدهما فقط سيغادر.

## التشغيل

**الأسهل — بدون خادم ولا إنترنت:**

```
افتح horror/game.html بالنقر المزدوج
```

**من المصدر (يتطلّب خادماً محلياً لأن الوحدات ES تُمنع على `file://`):**

```bash
cd horror
python3 -m http.server 8000
# ثم افتح http://localhost:8000/
```

**لإعادة بناء ملف اللعبة الواحد بعد تعديل المصدر:**

```bash
node build.mjs                      # يكتب game.html
node build.mjs --artifact out.html  # نسخة للتضمين داخل صفحة مستضافة
```

> إن شُغّلت اللعبة داخل إطار لا يسمح بقفل المؤشّر، تكتشف ذلك تلقائياً وتتحوّل
> إلى النظر عبر تحريك الفأرة نحو حواف الشاشة.

## المتطلبات

متصفح يدعم **WebGL2** (Chrome / Edge / Firefox / Safari حديث) وبطاقة رسوميات
تدعم التسريع. للحوارات الصوتية يُفضّل وجود صوت عربي مثبّت على النظام؛ إن لم
يوجد فستعمل اللعبة بالترجمة النصية الموقوتة تلقائياً (تُخبرك شاشة الإعدادات
بالحالة).

## التحكم

| الفعل | المفتاح |
|---|---|
| الحركة | `W A S D` |
| ركض / انحناء | `Shift` / `Ctrl` |
| النظر / هجوم / تصويب | الفأرة / الأيسر / الأيمن |
| تفاعل | `E` |
| الكشّاف | `F` |
| إعادة تلقيم | `R` |
| تبديل السلاح | `1`–`4` أو العجلة |
| تخطّي الحوار | `Space` |
| إيقاف مؤقت | `Esc` |

## الأسلحة — كيف تحصل عليها

تبدأ بيدين فارغتين عمداً؛ السلاح جزء من القصة لا شيء تملكه من البداية:

| السلاح | المفتاح | متى تحصل عليه |
|---|---|---|
| الكشّاف | `F` | السقيفة في الفصل الأول |
| فأس الحطب | `2` | تلقائياً عند أول وحش في الفصل الثاني |
| مسدس | `3` | في درج بالمكتبة، الفصل الثاني — ابحث عنه |
| بندقية صيد | `4` | بعد مشهد المذبح، الفصل الرابع |

الزر الأيسر للهجوم، الأيمن للتصويب على الشعيرة، `R` لإعادة التلقيم،
والأرقام `1`–`4` أو عجلة الفأرة للتبديل. إن بدأت من قائمة **اختيار الفصل**
فستُسلَّم عتاد الفصل المناسب تلقائياً.

## الفصول

1. **الطريق المهجور** — الوصول، وتعلّم الأساسيات. لا أعداء.
2. **البهو المظلم** — اجمع ثلاثة مصاهر وأعد الكهرباء. أول وحش، وأول سلاح.
3. **القبو الغارق** — أدر ثلاثة صمامات لتصريف المياه. ثم يحدث ما لا يمكن التراجع عنه.
4. **المذبح** — المشهد المحوري. لا قتال، لا خيار.
5. **الانتقام** — الراعي، بثلاثة أطوار.

## ملاحظة عن «DX12 Ray Tracing»

تتبّع الأشعة العتادي (DXR) وواجهة DirectX 12 **لا يمكن تشغيلهما في المتصفح** —
لا يوجد مسار لذلك من صفحة ويب. المطبَّق هنا هو خط أنابيب مكتوب يدوياً يعطي نفس
اللغة البصرية عبر تتبّع أشعة في فضاء الشاشة على WebGL2:

- انعكاسات بتتبّع شعاع لكل بكسل مع تنقيح ثنائي وتلاشي فرينل
- انسدال محيط بتتبّع أشعة في نصف كرة
- إضاءة حجمية بتتبّع شعاع مع ظلال من مخزن العمق
- إزالة ضجيج بالتراكم الزمني، وتوهّج، وتدرّج ACES
- مواد PBR مُولَّدة إجرائياً بالكامل

تفاصيل المقارنة مع DXR ومسار النقل إلى محرك أصلي في
[DESIGN.md](DESIGN.md#٧-الرسوميات).
